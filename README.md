# Dead Man’s Draw (C++)

A C++ implementation of the Dead Man’s Draw card game with 2 players, focusing on object-oriented design, game logic, and rule handling.

--
## Overview

This project simulates the core mechanics of Dead Man’s Draw, a card game where players draw cards to build their loot while avoiding busting.

--
## The implementation focuses on:

clean class design
accurate rule enforcement
state management during gameplay
Features
Full game logic implementation
Card drawing and bust mechanics
Special card effects (e.g. Anchor, Chest, Key, etc.)
Turn-based gameplay system
Object-oriented design using C++
